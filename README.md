# compass-servlet

OSS（[Jakarta Servlet](https://github.com/jakartaee/servlet)）への貢献の作業記録。

仕様（[`jakarta.servlet-api`](https://github.com/jakartaee/servlet/tree/main/api)）に書かれた契約と、実装（[Tomcat](https://github.com/apache/tomcat)）の実際の振る舞いを記録する。

| ディレクトリ | 中身 |
|---|---|
| `work/` | 作業ごとの記録（1作業1ディレクトリ） |
| `sharing/` | 作業に属さない横断的なもの |
