# early hints の TCK テスト

- Repo: [jakartaee/servlet](https://github.com/jakartaee/servlet)
- Issue: [Create TCK tests for early hints](https://github.com/jakartaee/servlet/issues/700)
- Status: Open

## 内容

JRE の HttpClient も Apache HttpClient も early hints に対応していない。

そこで、確認する項目を次の7つに絞り、ソケットへ直接読み書きする単純なクライアントで
テストを書けるのではないか、という案が示されている。

| # | 対象 | 内容 |
|---|---|---|
| 1 | 103 | 中間レスポンスが返り、ステータスが 103 |
| 2 | 103 | 指定したヘッダが、指定した値で存在する |
| 3 | 103 | それ以外のヘッダは見ない |
| 4 | 200 | 最終レスポンスが返り、ステータスが 200 |
| 5 | 200 | 指定したヘッダが、指定した値で存在する |
| 6 | 200 | 指定したヘッダが存在しない（できれば） |
| 7 | 200 | それ以外のヘッダは見ない |

103 と 200 の振り分けは並び順による整理で、Issue に明示はない。

## 懸念

レスポンスの差異が大きいと、クライアントが複雑になる。テストで自分が設定したヘッダだけを
対象にすれば、これはほぼ避けられるとしている。ただし、削除したヘッダを対象に含めるかは
未確定である。

## 未解決

再利用できる TCK のユーティリティは見つかっていない。
